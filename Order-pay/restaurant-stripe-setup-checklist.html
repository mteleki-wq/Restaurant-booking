Restaurant Stripe Setup

Follow the steps in order. Tick each box only when that step is finished.

Setup progress 0 / 7 complete
Security: Do not type or store any Stripe secret key on this instruction page. Copy keys directly from Stripe into the secure restaurant setup panel.

1Open the restaurant's Stripe API keys

In the restaurant's own Stripe account, go to Developers → API keys.

Copy the Secret key that starts with sk_test_, then paste it into Their secret key in your platform.

Open Stripe API Keys

2Copy the restaurant webhook URL

Use the URL shown in your platform for this restaurant. It must include the restaurant code at the end.

https://tehxobdokbvqtwtgqzrh.supabase.co/functions/v1/stripe-webhook?v=restaurant-code

3Create a webhook endpoint in Stripe

Go to Developers → Webhooks, choose Add endpoint, and paste the webhook URL from Step 2.

Open Stripe Webhooks

4Select these 3 Stripe events

Add exactly these events to the webhook endpoint:

checkout.session.completed
checkout.session.expired
charge.refunded

5Copy the webhook signing secret

After the endpoint is created, open it in Stripe and reveal the signing secret.

Copy the new value starting with whsec_ and paste it into Their webhook signing secret in your platform.

6Save the restaurant's Stripe keys

In your restaurant setup panel, click Save their keys.

Confirm the Stripe section changes from NOT CONNECTED to CONNECTED.

7Final restaurant check

Make sure the restaurant has accepted the required terms and the ordering/payment status is ready.

Then perform one test order before handing the restaurant over to staff or going live.

Setup checklist complete.
The Stripe connection steps have all been ticked. Now confirm the platform shows the restaurant as connected and complete one test order.
