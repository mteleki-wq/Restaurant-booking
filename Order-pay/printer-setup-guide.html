If something doesn't match

A few things that trip people up, and what they usually mean.

The self-test page won't print

Confirm there's paper loaded and the lid is fully closed. Some models want the lid open before you power on, then closed once it starts — if the FEED-and-power combination above doesn't work, the printer's own quick-start card will have the exact one for that model.

The browser can't reach the printer's IP address

Almost always a WiFi mismatch — double-check the phone or laptop you're using is on the exact same network the printer just connected to, not a guest network or a different band (2.4GHz vs 5GHz can appear as separate networks on some routers).

It asks for a username and password I don't have

Star ships a default login on the printer's box or included documentation. If those don't work, the network interface may need a reset — worth checking Star's support site for that specific model before assuming something's broken.

Still says "Never connected yet" after restarting

Double check the exact URL was pasted in full, with nothing extra before or after it. Confirm CloudPRNT Service is actually set to Enable, not just entered and left disabled. And give it a minute past the restart — the first poll isn't always instant.

It's connected, but Test Print doesn't produce paper

Connection and printing are two separate proofs — "Last heard from" only confirms the printer can reach the address, not that a specific print job worked. If it's genuinely connected but nothing prints, that's worth reporting back with what the printer's own status shows.
