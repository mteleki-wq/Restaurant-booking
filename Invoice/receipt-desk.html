How to bring receipts from Apple Notes
  1. Open the note and open the receipt image or scanned PDF.
  2. Use its Share menu to save the original file to Files. For a multipage scan, share the whole PDF.
  3. Here, select Choose receipts and select your saved files together.
  4. Check the date, supplier, total and GST. Tick Reviewed, then export.

A shared Notes folder link cannot be imported. A folder screenshot contains thumbnails, not the original receipts. For HEIC photos, export a JPG or use a clear screenshot of the individual receipt.

Your workbook mapping & important checks

A = Date · B = Supplier / description · C = Transport · N = Energy Aus · S = No GST. All other input columns are blank in the export, so never paste over an occupied row.

Transport exports the full receipt total; your workbook already applies private use separately. Energy exports the percentage you enter as its business share; confirm this before review. GST shown in the register is the invoice GST, not a calculated tax claim.

Your supplied file is named 2026–2027 but its headings say 2025–2026, and it contains existing entries. This tool does not change those headings or overwrite that file. Check the financial year before pasting.

Your workbook derives GST by dividing some category totals by 11. Mixed-GST receipts are blocked from workbook export because that formula may not match the actual GST; they remain available in the detailed register. Resolve those entries separately in your accounts.

Saving and privacy

This batch lives in the current browser tab only. Use Save batch before closing, then Restore saved batch later. The saved batch includes extracted text and figures, but not original images/PDFs; keep those in Notes or Files. There is no automatic connection to Apple Notes or your Excel file.

On-device mode processes files in your browser. AI mode sends each selected original to the configured server and OpenAI for two readings; it does not send your Excel workbook. The app does not retain the original uploads or AI responses on your server. OpenAI data policies still apply. Two readings can share an error, so always review. Reading libraries and English language data load from jsDelivr and the Tesseract language-data service. On-device mode needs no key. AI mode requires a server-side API key and a receipt-tool password; the API key is never placed in the HTML. Open this tool from a website in Safari or a desktop browser; the iPad Files preview does not run the tool.
