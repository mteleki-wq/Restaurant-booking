WebEscapade · Stage 1

Image migrator.

Takes a site file with photos baked into it, moves those photos to Supabase Storage, and hands back the same site pointing at real image URLs. Nothing else in the file is touched.

The restaurant's Supabase login, or your own platform admin account. Uploads are permission-checked, so this can't be skipped.

Must match the slug in Supabase — it decides the folder, and you can only write to venues you staff.

Your source/site-editable.html. Migrate the master, then publish from it.
