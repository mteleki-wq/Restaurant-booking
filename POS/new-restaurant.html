The restaurant

Goes inside every QR code. Settle it now — changing it later means reprinting every table.

Their Supabase project

From that project: Settings → API.

Use the anon key. The service_role key must never go into a page guests can read — this tool refuses one if you paste it.

Access

Create this login in their project first, under Authentication → Users, with Auto Confirm ticked. The script stops with a clear message if it is missing, rather than leaving a restaurant nobody can administer.

Where the ordering page will live

The address a guest's phone reaches when they scan. It goes into every QR code, so it must be the final public address.
